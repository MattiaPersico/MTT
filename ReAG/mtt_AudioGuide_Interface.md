# mtt_AudioGuide_Interface

## What it is

ReaImGui front-end for AudioGuide (ReAG). The user selects the target and corpus media items in the main window, configures the segmentation, corpus, superimpose and search-pass parameters, and the script runs the AudioGuide segmentation and concatenation Python scripts from the bundled ReAG environment, then imports the rendered output back into the project. It hosts a preferences window (environment, AudioGuide and Python3 paths, environment download) and a search-pass configurator window.
